# Static Instances Demo

This project applies [Unity Static Instances](https://github.com/yugo-unity/unity-static-instances)
to the URP 3D Sample demo (Oasis scene).

For details about the Static Instances package — features, requirements, setup and
documentation — see the [unity-static-instances](https://github.com/yugo-unity/unity-static-instances)
repository.
